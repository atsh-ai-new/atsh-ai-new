## خريطة أولية للمسارات الحالية
- `/api/orders`: شراء باقة، وينشئ مشروعًا مرتبطًا للحساب المسجل.
- `/api/customer/auth/project-drafts`: مسودات العميل، ثم `/:id/submit` لتسجيل مشروع الإدارة.
- `/api/admin/journey/projects`: مشروع الإدارة وحالاته ورسائله.
- `/api/admin/commercial/*` و`/api/customer/commercial/*`: العروض والعقود والفواتير.
- `/api/admin/team`: إدارة حسابات الفريق (ليست وحدها نظام إسناد مهام).
- `/api/admin/builder/*`: خطط ومهام بناء مستقلة تحتاج ربطًا بالمشروع.
- `/api/admin/pages/:slug` ↔ `/api/site-content/:slug`: تعديل ونشر وقراءة المحتوى.
