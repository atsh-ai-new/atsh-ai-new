# Add-on launch tariff — 2026-11-27 (EGP)

This assumes reusable components and the bounded scope in the migration. A new bespoke engine or scope expansion requires separate agreement. No domain, hosting, recurring provider charges, payment fees, or paid certificates included. Never order an add-on already included in the chosen product; basic security is not an optional paid feature. These are catalog orderable implementation scopes, not claims of already deployed customer modules.
