# ATSH AI — عامل تحريك الصورة الناطقة

مسار اختياري على جهاز Windows/Linux، وليس على سيرفر الإنتاج. يحتفظ السيرفر بالمشروع وطابور المهام ويولد الصوت العربي بالمحرك الحالي. الكمبيوتر يسحب الصورة والصوت بمفتاح مستقل عبر HTTPS، يشغّل نموذج SadTalker المثبت محليًا، ثم يعيد MP4 إلى المشروع نفسه. لا يتطلب رصيد API ولا اتصالًا واردًا إلى الكمبيوتر.

## حدود الإصدار
شخصية واحدة وصورة واضحة بوجه واحد، مشهد ثابت من 3 إلى 8 ثوانٍ، جملة عربية قصيرة، تحريك الشفتين والرأس والوجه. لا يعد بتحريك الأطراف أو المشي أو تركيب عناصر متعددة. لا تضاف موسيقى أو نصوص أو خلفيات منفصلة في هذا المسار. مسار الكرتون القديم مستقل. الأداء والجودة غير مضمونين على معالج i5-6300U وذاكرة 8 جيجابايت؛ اختبر أولًا. لا تستخدم صور أشخاص دون الإذن المناسب.

## تحسينات الإنتاج على CPU
- يتطلب العامل صورة أمامية بوجه واحد ظاهر بوضوح وحجم مناسب، ويفحص الصورة محليًا قبل الاستدلال. كاشف الوجه إرشادي وقد يرفض الصور الصعبة أو الجانبية.
- لا يُرسل الصمت المضاف لملء المشهد إلى النموذج افتراضيًا؛ تثبت الإطارات قبل الكلام وبعده، مع الحفاظ على مدة المشهد والصوت. استخدم `--full-motion` عند الحاجة إلى الحركة خلال الصمت أيضًا. لا يتوقع تسارع مماثل إذا استمر الكلام طوال المشهد.
- `--cpu-threads` يتيح تجربة 1–8 خيوط (الافتراضي 2)، دون ضمان ارتفاع الأداء. جودة الحركة والسرعة تحتاجان اختبارًا فعليًا.

## إعداد محلي
1. ثبّت Python وGit وFFmpeg باتباع تعليمات [مستودع SadTalker الرسمي](https://github.com/OpenTalker/SadTalker). استخدم بيئة Python مستقلة متوافقة مع إصدار النموذج، وتأكد من أن PyTorch يعمل على CPU. لا تثبت حزم النموذج على حاوية المنصة.
2. اتبع تعليمات المستودع لتنزيل ملفات النموذج الرسمية. افحص ترخيص الكود والأوزان والمكونات التابعة قبل أي استعمال تجاري. لا تنزل ملفات أوزان من مصادر عشوائية. العامل لا ينزل أو ينفذ تثبيتًا تلقائيًا.
3. من مجلد هذا العامل، اختبر محليًا بصورة وصوت قصيرين مصرح باستخدامهما (الملف الناتج يجب ألا يكون موجودًا بعد):
   ```powershell
   python worker.py --model-dir "C:\SadTalker" --python "C:\SadTalker\venv\Scripts\python.exe" --benchmark-image "C:\test\portrait.png" --benchmark-audio "C:\test\speech.wav" --benchmark-output "C:\test\result.mp4"
   ```
   راجع جودة الفيديو والزمن على الجهاز نفسه. الإعداد الافتراضي CPU، 256، batch 1، حتى 90 دقيقة للاستدلال. لا تفعّل الخدمة إذا كان الاختبار غير مقبول. لا يدعم هذا الإصدار تشغيل نماذج الجسم الكاملة.
4. بعد نجاح الاختبار ومراجعة الترخيص، أضف متغير البيئة السري `PORTRAIT_WORKER_TOKEN` في **خادم الـAPI فقط** (64 رمزًا hex من مولد عشوائي آمن، مثل `openssl rand -hex 32`). لا تضعه في Git أو الواجهة العامة. أعد نشر API. يحتاج عامل الصوت الحالي إلى `CHARACTER_SERVICE_URL` و`CHARACTER_SERVICE_TOKEN`. لا حاجة لإعداد n8n جديد.
5. شغّل العامل:
   ```powershell
   python worker.py --model-dir "C:\SadTalker" --python "C:\SadTalker\venv\Scripts\python.exe"
   ```
   أدخل المفتاح في المطالبة المخفية. لا تشاركه في محادثة أو تضعه في سطر الأوامر. أبق الجهاز متصلًا بالكهرباء والإنترنت، ولا تدعه يدخل في السكون أثناء الإنتاج. يدعم العامل أيضًا متغير `ATSH_PORTRAIT_WORKER_TOKEN` عند التشغيل كخدمة، ويزيله من بيئة عمليات النموذج. اختيار `--device cuda` اختياري للأجهزة المتوافقة فقط.
6. افتح منشئ المحتوى في لوحة الإدارة؛ اختر مشروع صورة ناطقة، ارفع صورة البطل، اكتب الحوار، ثم اعتمده واختر زر إنتاج الصورة الناطقة. حالة الاتصال تظهر في صفحة الإنتاج. إن كان الجهاز غير متصل ولم تنته مهلة المشروع، تبقى المهمة في الطابور. مدة الانتظار الافتراضية ساعتان، ويمكن ضبطها عبر `CONTENT_STUDIO_GENERATION_TIMEOUT_MINUTES`.
7. يمكنك إلغاء الإنتاج من لوحة الإدارة؛ تُلغى صلاحية تسليم المهمة فورًا، ويتوقف العامل عند نبضة الاتصال التالية. لا تستخدم مفتاح العامل على جهاز غير موثوق، فهو يتيح الوصول إلى الصور والأصوات الخاصة بمهام هذا المسار. يمكن تعطيله بإزالة متغير البيئة من الخادم وإعادة نشر الـAPI. الملفات الوسيطة في مجلد مؤقت محلي، وتحذف في نهاية التشغيل العادي.

## التحقق
`python -m unittest discover -s portrait-worker -p 'test_*.py'` من source.
اختبارات الوسائط تستخدم نموذجًا وهميًا لاختبار خط النقل فقط؛ اختبار SadTalker الفعلي على الجهاز مطلوب قبل الإتاحة.
