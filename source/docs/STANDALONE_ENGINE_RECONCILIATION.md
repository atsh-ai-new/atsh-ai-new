# توحيد محرك رحلة العميل — المرحلة الثامنة

- تمت مراجعة محرك `feature/ai-customer-journey-standalone`، وخاصة `standalone-assistant/src/assistant.js`.
- محرك GitHub التجريبي يستخدم ذاكرة مؤقتة ويتيح ردًا تجريبيًا بدون مفتاح API. لم يُستخدم ذلك المسار في الإنتاج.
- توحيد سياسة المحادثة وتحليل ردود OpenAI في `backend/src/journey-engine.js`، ويستخدمها الآن مسارا الموظف والعميل.
- يبقى PostgreSQL مصدر الحقيقة لحالة المشروع والرسائل والطلبات؛ ويظل التسعير الرسمي في الخادم.
- لا يقوم المحرك بتنفيذ الدفع أو النشر أو استدعاء n8n.
- هذا دمج **وظيفي لسياسات المحرك** وليس نقلًا حرفيًا لكل ملفات المحرك المستقل أو دمجًا مع النسخة الأحدث على السيرفر.
- يلزم اختبار PostgreSQL وOpenAI وn8n في بيئة تشغيل آمنة قبل النشر.
