# Stage 38 — Approved delivery orchestration

Added `backend/src/reviewed-delivery-orchestrator.js` and five focused tests. It connects the **logical** sequence agent generation → immutable draft awaiting human approval → Forgejo publish → isolated tests → signed preview request. Failures block downstream stages.

**Not yet wired into production:** Provide persistent draft store with SHA-256 content digest, transactional human approval and permission checks, durable stage writes and idempotent locking, checkout of exact Forgejo commit into a dedicated test worker, and a trusted preview deployment service. The existing Docker test runner and preview dispatcher can be used as adapters after those prerequisites. Do not run untrusted builds on the main ATSH server. No real preview URL is generated by this stage.

Verification: `node --test backend/test/*.test.js` and `node --check backend/src/reviewed-delivery-orchestrator.js`.
